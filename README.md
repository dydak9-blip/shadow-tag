# 그림자 술래

최대 5인 실시간 1인칭 공포 술래잡기 게임입니다. 안드로이드 앱(APK) 또는 휴대폰 브라우저로 플레이합니다.

- 한 명이 **방 만들기** → 다른 사람들은 **QR 스캔으로 참가** 또는 4자리 코드 입력 (2~5명)
- 모두 한곳에서 시작, 10초 뒤 무작위로 한 명이 술래로 변신
- 도망자: 3분 버티기 또는 열쇠(2개)로 출구(2개) 탈출 / 스턴건(라운드당 1회) / 손전등(10초, 5초 완충) / 잡히거나 탈출하면 맵 전체 관전
- 술래: 닿으면 잡기 / 질주(130%, 쿨 20초) / 덫 2개(1초 기절+위치 발각) / 마지막 15초 1.5배 광폭화
- 15초마다 2초간 미니맵에 전원 위치 공개
- 3라운드: 미로 → 폐건물 → 숲
- 혼자 하기: 봇이 술래
- 이어폰 권장: 3D 발소리, 술래가 가까울수록 커지는 심장 소리

## 구조
- `index.html` — 다운로드 페이지 (기기별 안내 + QR)
- `play/index.html` — 게임 본체 (웹 버전, 앱도 이 파일을 그대로 씀)
- `android/` — 안드로이드 WebView 앱. `android/build-assets.sh`로 게임을 앱에 넣고 Gradle로 빌드
